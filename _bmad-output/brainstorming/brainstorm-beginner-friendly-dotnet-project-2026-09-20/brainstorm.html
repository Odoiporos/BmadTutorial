05 · The fence

Strict v1 means
knowing where to stop.

These boundaries translate the failure-avoidance lens into a project promise. The keepsake describes the shape; it does not implement the app.

Inside the fence

  • Console application
  • Exactly one entity: expense
  • Four core operations
  • Local persistence only
  • Seeded sample data
  • A single happy-path interface

Not in v1

  • Authentication
  • Deployment requirement
  • Web UI or API
  • External services
  • More than one external package
  • “Just one more” feature

“The best beginner project has a tiny domain but several natural layers.”

Choose small. Learn wide. Finish.
